# Employee-Task-System

A simple and responsive Employee Task & Attendance Management System built using **HTML, CSS, and Vanilla JavaScript**. This project demonstrates basic employee management features such as attendance tracking, task assignment, employee records, and dashboard statistics. All data is stored in the browser using **Local Storage**, so no backend or database is required.

---

## Features

### Authentication
- Simple Login Page
- Show/Hide Password
- Basic Form Validation
- Dummy Login Authentication
- Logout Functionality

### Dashboard
- Total Employees
- Present Employees
- Pending Tasks
- Completed Tasks
- Welcome Message
- Current Date

### Employee Management
- Add Employee
- Edit Employee
- Delete Employee
- View Employee Details
- Search Employee by Name
- Filter by Department

### Attendance
- Mark Employee as Present or Absent
- Automatic Dashboard Updates

### Task Management
- Assign Tasks
- Update Task Status
- Pending
- In Progress
- Completed

### User Interface
- Responsive Layout
- Sidebar Navigation
- Dashboard Cards
- Employee Table
- Popup Modal
- Dark Mode
- Mobile Friendly Design

### Data Storage
- Browser Local Storage
- Data Persists After Refresh
